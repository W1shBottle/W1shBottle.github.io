**目标：期末卷面60分以上。** 练习时尽量达到65～70分水平，为计算失误和题型变化留出余量。

适用起点：掌握变量、循环和数组，递归与数据结构相对薄弱；部分重点算法已经学过，但仍需闭卷和新数据练习。本计划按相对天数安排，可根据考试日期和每日可用时间调整。

## 一 复习时间与范围

重点路线预计还需 **35～50小时**，可先按14天、每天3小时，共42小时安排。学习、练习、计时和订正都算在内。

| 任务 | 参考时间 | 内容 |
| --- | ---: | --- |
| 复杂度与分治 | 5小时 | 递推式、归并、二分与选择问题 |
| 动态规划核心 | 7小时 | 矩阵连乘、图像压缩、0–1背包、最大子段和 |
| 回溯与分支限界 | 7小时 | 子集树、剪枝、队列、优先队列和上界 |
| 贪心 | 4小时 | 排队、区间覆盖、活动安排与背包对比 |
| LCS与图基础 | 4小时 | 公共子序列、图的基本概念与课件典型题 |
| 其他真题变式 | 3小时 | 金块问题、截止期任务、跳台阶等 |
| 综合计时与错题 | 8小时 | 独立作答、订正和重做 |
| 机动与薄弱点 | 4小时 | 复学卡点、手算失误和易错细节 |
| **合计** | **42小时** | 学习与练习均已计入 |

时长是规划估计，不保证通过，也不需要在上述预算外再加一遍刷题时间。若要较完整覆盖第二轮课件例题，可预留约 **50～75小时**；这是更大范围的总预算，不与35～50小时相加。

## 二 往年题重点与当前起点

手头材料分为2023、2024秋、2025春、2025冬四组回忆题。2025年春的多份回忆高度重合，按一组计算；不同年份、专业的考题和本学期范围可能有差异。

| 题型 | 出现的组数 | 常见要求 |
| --- | --- | --- |
| 复杂度与递推 | 4组中4组 | 读代码、列递推式、求上界 |
| 排队最小等待 | 4组中4组 | 说明策略、给顺序、计算 |
| 回溯搜索与剪枝 | 4组中4组 | 画树、说明剪枝或设计搜索 |
| 图像压缩／像素分段 | 4组中3组 | 列状态、填表、还原分段 |
| 矩阵连乘 | 4组中2组 | 计算过程、最少次数与括号顺序 |
| 中位数／前k大选择 | 4组中2组 | 设计算法并分析复杂度 |
| 归并排序 | 4组中1组 | 伪代码、排序步骤、时间上界 |

这只是现有回忆资料的计数，**不能当成今年的出题概率**。2025年春最后一题的回忆存在分歧，仅能确认涉及优先队列或搜索思路，不能断定具体题型。

已讲过的内容包括复杂度、汉诺塔、二分、归并、随机选择；排队、区间覆盖、活动安排；最大子段和、0–1背包、矩阵连乘、图像压缩；回溯与分支限界的背包例题。下一步重点是独立写过程、换数据练习和补未学内容。

## 三 14天执行表

每天按约3小时安排。常规日可分为：理解约1小时、动手练约1.5小时、订正约0.5小时。计时日调整为限时作答和订正。

### 第1～7天：基础与高频专题

1. **复杂度与递推式**：复习O、Ω、Θ；练汉诺塔、二分、归并，以及 `T(n)=2T(n/2)+5n²`。验收：闭卷写出两种递推式及推导。
2. **分治与选择**：手写归并过程和伪代码；练金块、二分；区分随机选择平均与最坏复杂度、确定性线性选择的最坏保证。验收：完成8个数的排序过程和1道选择题。
3. **贪心**：练排队、区间覆盖、活动安排；复习可分割背包和0–1背包的区别。验收：排队、覆盖各1题，写出规则与复杂度。
4. **矩阵连乘**：先算3个矩阵，再换数据算4个矩阵；记录最优切分、括号和最少数乘。验收：不看例题完成1张表并还原顺序。
5. **图像压缩**：复习段开销和最大位宽，练末段枚举、记录段长及逆向还原。验收：完成9像素回忆题，列出dp候选值与分段。
6. **背包与DP**：练0–1背包二维表、选或不选及方案还原；复习最大子段和与简单状态变式。验收：独立填1张背包表并写状态转移。
7. **回溯**：画完整二叉子集树，再画超重剪枝后的树，标注重量、价值和搜索顺序。验收：完成1道背包搜索树和剪枝说明。

### 第8～14天：补缺与综合练习

8. **分支限界**：练队列式、优先队列式；按单位价值排序，计算分数背包上界，记录入队、出队和best。验收：独立完成1棵搜索树，标出上界与取出顺序。
9. **LCS与图基础**：补最长公共子序列的状态、填表与还原；认识顶点、边、路径和生成树。验收：完成1个LCS表，能区分路径与生成树。
10. **2024秋回忆**：限时完成可还原题干，练递推式、金块、最大子段和、排队、图像压缩及回溯背包。验收：逐项检查，标记未知或不完整的题干。
11. **2025春回忆**：练汉诺塔、归并、矩阵连乘、排队和回溯背包；搜索题结合不同回忆练习。验收：限时写出过程，标明最后一题的回忆分歧。
12. **2025冬回忆**：练前k大、像素分段、DP变式、排队、二进制回溯和区间覆盖。验收：按已知要求写伪代码与复杂度。
13. **2023回忆**：练复杂度、中位数选择、矩阵连乘、图像压缩、排队及整数解回溯。验收：重做不熟练题型，检查最坏与平均复杂度。
14. **综合与补漏**：闭卷选择两组薄弱题限时作答，重做错题，并复述各方法的适用条件。验收：完成错题重做和考前清单。

完成标准是能在纸上复现；如果第一次只是看懂讲解，使用机动时间补做。回忆卷并非完整原卷，缺失题干或分值可用课件例题补充，但要标明补充题，不能当作原题。

计时优先按本学期正式考试时长执行；未确认时，可以先用约90～120分钟练习，再留时间订正。

## 四 完整课件范围与优先顺序

### 第一轮：先练到能动手做

- [复杂度与递推](/posts/cumt-algorithms-final-1/)：循环计数、O／Ω／Θ；汉诺塔、二分、归并及2024秋递推变式。
- [递归与分治](/posts/cumt-algorithms-divide-conquer/)：归并步骤与伪代码、金块、快速排序基本划分、选择问题；区分随机选择的平均O(n)与最坏O(n²)，以及确定性线性选择的最坏保证。
- [动态规划](/posts/cumt-algorithms-dp/)：状态、边界、转移与还原；矩阵连乘、图像压缩、0–1背包、最大子段和；补LCS和简单变式。
- [贪心](/posts/cumt-algorithms-greedy/)：排队等待、区间覆盖、活动安排；能说明选择依据并写算法与复杂度。
- [回溯](/posts/cumt-algorithms-backtracking/)与[分支限界](/posts/cumt-algorithms-branch-bound/)：二进制串、背包取舍树、可行性与上界剪枝；区分深度优先、队列式和优先队列式。

### 第二轮：依据范围和时间补充

- **分治**：棋盘覆盖、大整数乘法、Strassen矩阵乘法、最近点对、循环赛。
- **DP**：凸多边形最优三角剖分、电路布线、流水作业调度。
- **贪心与图**：最优装载、哈夫曼编码、单源最短路径、最小生成树、多机调度；补点、边、路径、树、队列等基础。
- **搜索**：排列树、旅行售货员、最大团、图着色、n皇后；分支限界的装载与最大团。

第二轮是课件覆盖，并非不会出题。根据课堂进度、最新考试范围和剩余时间决定取舍。

## 五 验收标准与答题方法

| 专题 | 最低验收标准 |
| --- | --- |
| 复杂度 | 对新代码数基本操作；给定递推式能列边界、展开并写出上界 |
| 分治 | 不看答案写归并拆分、合并和复杂度；选择题能解释只递归一侧并区分平均、最坏情况 |
| 贪心 | 写出选择规则和排序依据；排队算等待不含自身服务时间，区间覆盖能处理空隙 |
| DP | 写状态、边界、转移、填表顺序和答案位置；能还原矩阵括号、图像分段和背包取舍 |
| 搜索 | 画完整树及剪枝后树，标层、重量、价值、上界与best；能写出队顺序、剪枝理由和最优解 |

每道题先识别问题与约束，写使用的算法及核心规则；再按题目要求写递推式、伪代码、画表或画树；最后给结果、复杂度和必要的还原过程。题目指定方法时按指定方法作答。

练习时换数据，不只重背原题。每题至少留一次不看答案重做，标记错误属于概念、步骤、计算还是时间分配。

最后一周争取完成至少两次独立限时练习，按练习题的参考答案覆盖约65～70分的内容，并重做错题。回忆题缺少分值时，只统计已完成的题型及步骤；练习结果不等同于真实卷面分数，也不保证通过。

## 六 时间调整与考场安排

| 每天有效时间 | 42小时参考计划 | 安排方式 |
| --- | --- | --- |
| 2小时 | 约21天 | 拆分3小时任务并顺延，每周保留一次整块计时 |
| 3小时 | 约14天 | 按第1～14天顺序执行，薄弱项使用机动时间 |
| 4小时 | 约11天 | 合并轻量任务，保留限时作答与订正 |

如果离考试不足两周，优先完成复杂度、排队贪心、矩阵连乘、图像压缩、回溯树与背包分支限界，仍留出至少一次计时和错题重做。压缩时间会增加风险，具体范围以本学期考试要求为准。

考场先通读题目，区分“写思路、伪代码、计算过程、画树、证明或复杂度”的要求；按分值和难度分配时间。表格和搜索树题先写状态、公式、边界与关键步骤，再补完整结果。遇到变式，先写能够确定的状态定义、策略或约束。

检查时重点核对：下标、背包重量、区间是否连续、贪心排序关键字及最优解还原。计算器、草稿纸、成绩构成及是否要求卷面单独及格，以本学期正式通知为准。

## 七 材料使用顺序

1. **课程课件**：算法概述、递归与分治、动态规划、贪心、回溯和分支限界。先使用本课程对应课件，再按需要参考其他版本。
2. **往年真题**：2023、2024秋、2025春整合、2025冬回忆题。相同试卷的重复回忆合并参考，题干不确定的地方不当成确定事实。
3. **专题笔记**：按照复杂度、分治、贪心、动态规划、回溯、分支限界查找状态、例题和伪代码。
4. **其他复习资料**：明确标为AI整理且可能有错误的文件只用于检索，不直接当标准答案；真题解析需与课件和题面交叉检查。
