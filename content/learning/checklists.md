- `[x]`：这一条明确的小练习或解释已有通过记录，不代表整门技术已经熟练。
- `[ ] 【已练习】`：接触过或在指导下做过，后续通过一个独立变体确认；不要求现在从头重写项目。
- `[ ] 【正在学】`：当前优先做。`[ ] 【已看课，待复习】`：看过相关课程但久未写，项目实践按实际情况记录；`[ ] 【待学】`：到对应阶段再做。`[ ] 【按需】`：有实际需求再选，不阻挡进入 AI。
- 勾选前能做到：**解释用途 → 自己改出一个小变体 → 预测并验证结果 → 能定位一个相关错误**。只看懂助手给的代码，不自动勾选。
- 网页和连续阅读版展示当前验收快照，不会因点击自动保存或同步个人进度。可下载自学包，在自己的Markdown中把 `[ ]` 改为 `[x]` 记录；已勾项只说明本项目作者已有相应证据，不代表每位读者都已完成。
- 每次只挑当前阶段 1—3 项；同类断言已明确跳过的练习不再补成欠账，不用完成率催进度。

- [ ] **C02【待学】效果评估**：采用离线固定集与交互反馈双口径。① 离线固定案例（开发集/留出集分开）记录真实样本数、结构合法率、事实忠实度、建议可用性/修改次数，保留失败例和人工判定理由；② 纳入 B09 反馈日志的真实采纳率（直接采纳 / 修改后采纳 / 驳回占比）与修改次数分布统计，并抽样归因。两类指标分开列示并标明实际分母，不只挑成功截图，无真实模型调用不将模拟结果计为效果数据。
- [ ] **C03【待学】延迟、用量与成本**：记录端到端耗时、失败/重试、输入输出 token 及计价依据；说明小样本限制，没有实测不写提升比例或并发规模。
- [ ] **C04【待学】失败分析与回归**：选一个真实问题，只改提示、上下文或解析中的一项；重跑固定集和留出集，解释改善与退化，并证明 AI 失败仍不影响业务。

## D：可选进阶模块（不阻挡 A→B→C 结项）

以下两项为按需进阶任务，不计入 A→B→C 结项门槛与主线完成率分母，均基于现有 Java / Spring Boot / MyBatis / MySQL 轻量实现，不引入 Milvus、Neo4j、微调或本地推理部署。

- [ ] **D01【按需】历史工单轻量检索（轻量 RAG）**：使用 MySQL 全文检索（`FULLTEXT`）或同设备/型号条件过滤，召回 Top 3 已解决（`RESOLVED`/`CLOSED`）且当前有权限查看的历史工单注入上下文，要求建议标明引用工单编号，查无依据则明确说明而非硬凑。验收须在 C 阶段同一批**留出集**上完成有/无检索对比回归，记录真实分母下的建议可用性、引用准确度、耗时与 token 增量变化，并保留至少 1 个误召回或无效召回样本分析。
